

\---



\## 🚀 Funcionalidades



\- Site responsivo com menu hambúrguer em dispositivos móveis.

\- Modo \*\*alto contraste\*\* para acessibilidade (WCAG 2.1).

\- Estrutura semântica com landmarks (`<header>`, `<main>`, `<footer>`).

\- Formulário de contato funcional.

\- Deploy automatizado via \*\*GitHub Pages\*\*.



\---



\## 🛠️ Tecnologias Utilizadas



\- \*\*HTML5\*\* e \*\*CSS3\*\* (semântica e responsividade).

\- \*\*JavaScript (ES6+)\*\* para interatividade.

\- \*\*Vite\*\* como bundler e otimizador.

\- \*\*Git/GitHub\*\* para versionamento e deploy.



\---



\## 📌 Fluxo de Trabalho (GitFlow)



\- `main` → versão estável em produção.  

\- `develop` → integração de novas funcionalidades.  

\- `feature/\*` → desenvolvimento de features específicas.  

\- `release/\*` → preparação de versões.  

\- `hotfix/\*` → correções rápidas em produção.



\---



\## 📝 Commits Semânticos



Exemplos:

\- `feat: adicionar botão de contraste`

\- `fix: corrigir bug no menu responsivo`

\- `docs: atualizar README com instruções`
